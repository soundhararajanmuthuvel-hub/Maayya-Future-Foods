# Maayya Future Foods — Smart Business Manager

A business management application designed for wholesale billing, direct point-of-sale (POS), cold-chain inventory batch tracking, retail shop outstanding balances, supplier purchases, operational expenses, and financial reporting.

---

## Project Overview

- **Product:** Maayya Future Foods — Smart Business Manager
- **Client Organization:** Maayya Future Foods
- **Application Type:** Single-User Web Application
- **Software Developer:** MSR Solutions

---

## Technology Stack

- **Frontend:** React 19 + TypeScript + Vite (Hosted on **Vercel**)
- **Backend:** Express API + Node.js (Hosted on **Render**)
- **Database:** PostgreSQL (Hosted on **Render**)
- **Styling & Icons:** Tailwind CSS v4 + Lucide React
- **PWA Capabilities:** Web Push Notifications, Offline Service Worker (Workbox)

---

## Core Modules

1. **Wholesale Billing:** Multi-brand invoice generation with batch allocation and partner branding.
2. **Direct POS:** Fast counter billing for walk-in retail customers.
3. **Purchases (GRN):** Inward stock tracking with batch numbers, manufacturing/expiry dates, and cold storage zone allocation.
4. **Inventory & Cold Storage:** Batch traceability across deep freezers and chillers with expiry alerts.
5. **Retail Shops Ledger:** Credit limits, invoice aging, and payment collection recording.
6. **Suppliers Ledger:** Vendor payables, payment terms, and disbursement logging.
7. **Expenses & Daily Cash:** Operational expense vouchers and evening cash drawer closing reconciliation.
8. **Reports:** Revenue, profit & loss, GST summaries, and ledger CSV exports.
